# complex_systems

金融以外の複雑系について、**数理を学び・実験で可視化し・楽しく知識を増やす**ためのリポジトリ。

## 目的

1. **数学的基礎**を身につけ、複雑系の数理（ABM 以外のアプローチを含む）に詳しくなる
2. **面白い実験を可視化**して、理解を体感に落とし込む
3. **研究の道具立て**（ツール・手法）を用途別に使い分けられるようになる

金融（確率過程・時系列・ファットテール・臨界性）で培った直観を足場に、隣接する複雑系の数理へ地続きで広げていく。

## ディレクトリ構成

```
complex_systems/
├── notes/         # 数学的基礎の手書きノート (Markdown + LaTeX)
├── experiments/   # 1 実験 = 1 ディレクトリ（理論メモ + コード + 可視化 + 気づき）
├── lectures/      # 手法・道具の講義資料 (PDF)
└── lib/           # 共通ユーティリティ
```

各実験ディレクトリは `README.md`（理論と気づき）とノートブックをセットにする。

## ツール・手法の使い分け（目的 3）

| 用途 | 道具 |
|------|------|
| 計算してプロットする実験 | Jupyter notebook |
| 対話的可視化（スライダーで挙動を探る） | marimo（リアクティブ notebook） |
| 腰を据えた理論調査 | Claude Code の `deep-research` 等の調査ワークフロー |
| 再現性・記録 | このリポジトリ（実験を git で蓄積） |
| 数式の理解 | `notes/` の Markdown + LaTeX |

道具そのものの使い方・使い分けは [`lectures/`](lectures/) に講義資料(PDF)として蓄積する。
