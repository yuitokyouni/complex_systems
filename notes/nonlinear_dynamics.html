非線形力学系の基礎ノート

複雑系の数理の入口。少数の決定論的な式から、不動点・周期・カオスといった豊かな挙動が生まれる仕組みを、ロジスティック写像を題材に整理する。

1. 力学系とは

状態が時間とともに決定論的に更新される系。離散時間なら

\[x_{n+1} = f(x_n)\]

という写像 (map) で表す。\(f\) を繰り返し適用する（軌道 orbit を追う）のが基本操作。連続時間なら微分方程式 \(\dot{x} = f(x)\) になる。

複雑系の文脈で重要なのは、\(f\) が非線形だと、たった 1 次元・1 パラメータでもカオスが現れること。線形系では絶対に起きない。

2. ロジスティック写像

\[x_{n+1} = r\, x_n (1 - x_n), \qquad x_n \in [0,1],\ r \in [0,4]\]

  • もともとは個体群動態モデル。\(x_n\) は環境収容力に対する個体数の割合。
  • \(r x_n\) が増殖、\((1 - x_n)\) が過密による抑制。両者の積（非線形項）が全ての面白さの源。
  • \(r \le 4\) なら \([0,1]\) が \([0,1]\) に写る（軌道が発散しない）。

3. 不動点とその安定性

不動点 (fixed point) \(x^*\) は \(f(x^*) = x^*\) を満たす点。

\[x^* = r x^* (1 - x^*) \;\Rightarrow\; x^* = 0 \ \text{または}\ x^* = 1 - \tfrac{1}{r}\]

安定性は微分（乗数 multiplier）\(f'(x^*)\) の絶対値で決まる：

  • \(|f'(x^*)| < 1\) → 安定（近傍の軌道が引き込まれる）
  • \(|f'(x^*)| > 1\) → 不安定（はじかれる）

\(f'(x) = r(1 - 2x)\) なので、

  • \(x^*=0\): \(f'(0) = r\) → \(r < 1\) で安定
  • \(x^*=1-1/r\): \(f'(x^*) = 2 - r\) → \(1 < r < 3\) で安定（\(|2-r|<1\)）

つまり \(r=1\) で 2 つの不動点が安定性を交換し（トランスクリティカル分岐）、\(r=3\) で非自明な不動点が不安定化する。

4. 周期倍分岐とカオスへの道

\(r = 3\) を超えると不動点が不安定化し、代わりに周期 2 の軌道（2 点を行き来）が安定になる。さらに \(r\) を上げると 2 → 4 → 8 → … と周期が倍々に増える。これが 周期倍分岐 (period-doubling bifurcation)。

分岐が起きる \(r\) の値 \(r_k\) は、有限の値 \(r_\infty \approx 3.5699\) に幾何級数的に集積する。その縮み率が

\[\delta = \lim_{k\to\infty} \frac{r_k - r_{k-1}}{r_{k+1} - r_k} \approx 4.6692\ldots\]

ファイゲンバウム定数 (Feigenbaum constant)。驚くべきは、この値が 写像の詳細によらない普遍定数であること（一山型写像なら何でも同じ値になる）。これは繰り込み群的な普遍性の現れで、複雑系における「ミクロの詳細に依らないマクロな法則性」の典型例。

\(r > r_\infty\) ではカオス領域に入るが、その中にも周期窓（例: \(r \approx 3.83\) の周期 3 窓）が点在する。

5. カオスの定量化：Lyapunov 指数

カオスの本質は初期値鋭敏性：近接した 2 軌道が指数的に乖離する。その指数的乖離率が Lyapunov 指数：

\[\lambda = \lim_{N\to\infty} \frac{1}{N} \sum_{n=0}^{N-1} \ln \left| f'(x_n) \right|\]

  • \(\lambda < 0\): 軌道が収束（不動点・周期軌道）→ 予測可能
  • \(\lambda > 0\): 指数的に乖離（カオス）→ 長期予測不能
  • \(\lambda = 0\): 分岐点・周期窓の縁

ロジスティック写像では \(f'(x_n) = r(1 - 2x_n)\) を軌道に沿って平均すればよい。\(\lambda(r)\) を描くと、分岐図の構造と完全に対応する（\(\lambda\) が 0 を上にまたぐ点で分岐・カオス突入が起きる）。

6. 金融との接続（メモ）

  • 初期値鋭敏性 = 長期予測の原理的限界。決定論的でも予測不能、という点は市場のランダムウォーク仮説とは別ルートで「予測困難性」を導く。
  • 普遍性（ファイゲンバウム）= ミクロに依らないマクロ法則。後の SOC・相転移で扱う「べき則の普遍性」と同じ思想の先取り。
  • 一見ランダムに見える時系列が、低次元の決定論的カオスかもしれない、という視点（→ アトラクタ再構成、相関次元など、後の実験で）。

  • 分岐図 (bifurcation diagram)、コブウェブ図 (cobweb plot)
