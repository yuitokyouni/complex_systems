# 同期現象と Kuramoto モデルの基礎ノート

バラバラに振動する多数の要素が、相互作用を通じて自発的に歩調をそろえる——
ホタルの一斉明滅、心筋細胞、脳波、手拍子、送電網の交流位相。これらを統一的に
説明するのが **Kuramoto モデル**。複雑系における「自己組織化」「協同現象」「相転移」の
最小モデルの一つ。

## 1. モデル

$N$ 個の位相振動子。各 $i$ は自然振動数 $\omega_i$（固有のテンポ）を持ち、全体と結合する：

$$\frac{d\theta_i}{dt} = \omega_i + \frac{K}{N}\sum_{j=1}^{N}\sin(\theta_j-\theta_i)$$

- $\theta_i\in[0,2\pi)$: 振動子 $i$ の位相
- $\omega_i$: 自然振動数。分布 $g(\omega)$（例: 平均 0 の正規分布）から引く
- $K\ge 0$: 結合強度。これが唯一の制御パラメータ
- $\sin(\theta_j-\theta_i)$: 位相差を縮める向きの引き込み（位相が近づくと小さく、揃うと 0）

## 2. 秩序変数：同期を測る一つの複素数

$$r\,e^{i\psi} = \frac{1}{N}\sum_{j=1}^{N} e^{i\theta_j}$$

- $r$（振幅, $0\le r\le1$）: **同期の度合い**。$r=0$ で完全バラバラ、$r=1$ で完全同期
- $\psi$（偏角）: 集団の平均位相

単位円上に全振動子を点で打ち、その**重心**を見ているのと同じ。重心が原点近く（散らばり）なら $r\approx0$、一塊なら $r\approx1$。

### 平均場表現（数値計算で重要）

秩序変数を使うと、結合項が各 $i$ について閉じた形に書き直せる：

$$\frac{d\theta_i}{dt} = \omega_i + K\,r\,\sin(\psi-\theta_i)$$

二重和 $O(N^2)$ が $O(N)$ になる。各振動子は「平均場 $(r,\psi)$ に引っ張られる」とも読める。
結合が生む秩序 $r$ が、その秩序自身を強める——自己無撞着な協同現象。

## 3. 同期の相転移

$K$ を 0 から上げていくと：

- **$K < K_c$**: 各自が自然振動数で回り、位相は散らばったまま。$r\approx 0$（非同期）。
- **$K > K_c$**: 自然振動数が中心に近い振動子から順に**引き込まれ（位相ロック）**、一塊になって回り始める。$r>0$ が自発的に立ち上がる（同期）。

これは温度を下げると磁石が自発磁化を持つのと同じ構造の **二次相転移**。$r$ が秩序変数、$K$ が制御パラメータに対応する。

### 臨界結合強度 $K_c$

自然振動数分布 $g(\omega)$ が単峰・対称なら、Kuramoto の自己無撞着解析から

$$K_c = \frac{2}{\pi\,g(0)}$$

- **正規分布**（標準偏差 $\sigma$）: $g(0)=\dfrac{1}{\sigma\sqrt{2\pi}}$ より $K_c = \sigma\sqrt{\dfrac{8}{\pi}} \approx 1.596\,\sigma$
- **Lorentz 分布**（半値半幅 $\gamma$）: $K_c = 2\gamma$

分布が広い（テンポがバラバラ）ほど $K_c$ は大きい＝同期しにくい、という直観に合う。

臨界点直上では $r \sim \sqrt{K-K_c}$ で立ち上がる（平均場相転移の臨界指数 1/2）。有限 $N$ では転移が少し鈍る（有限サイズ効果）。

## 4. ロジスティック写像（実験01）との対比

| | 実験01 ロジスティック写像 | 実験02 Kuramoto |
|---|---|---|
| 系 | 1 変数の離散写像 | N 体の連続力学系 |
| 制御パラメータ | $r$ | $K$ |
| 起きること | 秩序 → カオス（複雑化） | 無秩序 → 秩序（自己組織化） |
| 鍵概念 | 分岐・カオス・普遍性 | 相転移・協同現象・臨界 |

「少数自由度のカオス」と「多自由度の自己組織化」は複雑系の両輪。後者は統計力学的視点
（実験06 Ising、相転移）へ直結する。

## 5. 金融・他分野との接続（メモ）

- 市場参加者の戦略の「同期」＝群集行動・バブル/クラッシュの一斉化。結合強度の上昇が
  協同現象を生むという描像は、流動性・情報伝播の文脈で示唆的。
- 送電網は文字通り Kuramoto 型（発電機の位相同期）。同期崩壊＝大規模停電。
- 臨界点近傍での「ゆらぎの増大・相関長の発散」は、SOC（実験03）や金融の臨界性とも通底。
